# Movie Seat Booking App

A lightweight seat reservation application built with vanilla JavaScript. Users can select a movie, choose available seats, view booking costs in real time, and confirm or cancel reservations.

## Features

* Dynamic movie selection
* Interactive seat booking interface
* Real-time seat count and price calculation
* Seat identification using column-row notation (e.g., A1, D3, H6)
* Occupied seat handling
* Booking confirmation and cancellation workflows
* Responsive UI

## Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)

## Project Structure

```text
├── index.html
├── index.css
└── index.js
```

## Key Concepts

* DOM Manipulation
* Event Handling
* Dynamic Rendering
* State Management
* Array Operations

## Usage

1. Select a movie.
2. Choose one or more available seats.
3. Review selected seats and total cost.
4. Click **Continue** to confirm booking or **Cancel** to reset the selection.
